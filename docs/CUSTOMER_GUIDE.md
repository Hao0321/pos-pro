# 客戶先付錢，怎麼記？

首頁搜尋「預收」，選「管理客戶、預收與抵付」，也可以直接進「客戶與款項」。目前由管理員操作；配對手機和電腦共用同一間店的資料。所有店家、全部功能免費。

1. 選客戶。第一次往來就按「新增往來客戶」，填名稱即可，電話可選填。同名的人各有自己的客戶代碼，款項不會自動合併。
2. 實際收到錢後，按「收到款項」，填金額、現金或銀行，勾選「我已實際收到這筆款項」，再保存。還沒交貨也可以先記，系統會保留客戶餘額。
3. 交貨請回「銷售與應收」記錄。再到客戶頁按「抵付帳單」，核對每張帳與建議金額，確認保存。這一步只分配已收到的錢，不會再收一次。

例如先收到 500 元，兩次交貨分別是 150 和 250 元：同一筆收款可以抵付兩張帳，剩下 100 元留在該客戶名下。收款、交貨和抵付都有各自的原紀錄，收入不會重複計算。

要退回尚未使用的餘額，按「退回餘額」，確認原收款、實際退款金額和原因。退款沿用原收款方式；現金需先開班。已抵付的部分需要退回時，先在原紀錄按「解除這筆抵付」，再從原收款退回。解除抵付只是把錢放回客戶餘額，不代表現金已退。較早的抵付紀錄可按「顯示更早的紀錄」找回。

記錯收款或退款，使用原紀錄的更正操作並填原因。先更正有效退款、解除有效抵付，才可沖銷整筆原收款。不要另開一筆來假裝舊紀錄不存在。

Agent 可以幫你填草稿：回客戶列表，打開「讓 Agent 幫我填收款草稿」，貼上它準備的內容，按「帶入並核對」。確認欄不會自動勾選，請自行核對實際收到的款項後保存。格式見 [Agent 建單協議](AGENT_DOCUMENT_PROTOCOL.md)。

切換明亮／海報風格，或繁中、英文、日文、簡中，會保留尚未完成的輸入。商品、客戶名稱、備註、售價與 TWD 幣別維持原文；介面語言不會替你換匯。

保存結果不明時，按「確認原操作結果」。系統會保留原編號並鎖住原草稿，重新開啟仍沿用同一筆，確認前不要重收款。還原舊備份後找不到原收款時，使用 [資料復原引導](RECOVERY_GUIDE.md) 找回完整帳本。

更新前請另存完整備份。使用客戶帳功能後，資料庫會阻擋不支援此功能的舊程式寫入；回退必須搭配升級前的資料副本。這裡記錄已發生的現金／銀行款項，不會向銀行扣款，也不代替稅務發票或完整會計關帳。
