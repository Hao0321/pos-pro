# 記錄日常支出

在「會計帳務 → 記錄費用」填金額與用途，按「記好這筆支出」。系統會自動產生借貸平衡的分錄並更新報表。

預設為雜費與現金。「分類、日期與付款」可選租金、水電、薪資、廣告等常用類別，或調整原有費用科目、銀行付款、尚未付款、日期與備註。進貨仍走進貨管理，讓數量、商品與成本一起保存；已啟用實際庫存成本時，不接受從費用表單手動增加存貨。

金額接受全形數字、正確千分位與小數，最多兩位小數。`1e2`、負數、零、多餘小數與不存在的日期不會被默默改成另一個金額或日期。畫面保留使用者原文，正式記錄使用精確的分、原有會計科目與報表。

輸入按店面、還原世代與帳號保存在目前裝置。離開頁面或重新開啟會接回；同一來源的兩個視窗透過 Web Lock 交接。第一次保存前先固定原編號，回覆不明時核對原回執，查不到才明確沿用原編號繼續。

日記帳取消補登記錄須再次確認。取消與原回執一起保存，舊草稿再次核對只會確認已取消，不會重新建立支出。沒有取消證明卻找不到原記錄時，系統保留輸入要求核對。已被庫存開帳凍結的歷史分錄沿用原限制。

此功能記錄已發生的支出，不執行付款、退款或額外庫存異動。收銀抽屜的現金進出沿用既有流程；目前不能把本次來源改善視為所有付款、抽屜、應付供應商與稅務情境都已整合驗收。
