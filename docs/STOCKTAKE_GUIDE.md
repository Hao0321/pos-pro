# 點一下庫存

開發版功能，尚未放進 2.16.0 安裝檔。所有店家、全部功能免費。

1. 開啟「實際點一下庫存」，填你實際點到的架上數量。
2. 按「看差異」，核對數量。
3. 勾選確認，按「確認保存」。

還沒投入製作的貨都要點，包含替客人留著的份數。已投入製作的不用再加；系統會把預留分開算。例如架上 9 袋、其中預留 2 袋，系統會算可賣 7 袋。

空白代表還沒點；真的沒有才填 0。可填三位小數。數量不足以供應預訂時，先核對原預訂。

離開再回來，草稿會接著用。資料有變會請你重新點過；回覆中斷時按「核對上次盤點」，不用再建一張。

需要 Agent 幫填時，展開「讓 Agent 幫填本頁」，複製資料包，貼上回覆。Agent 只整理你實際點到的數量，最後仍由你確認。多出的貨先標成本待確認。

保存後可匯出報告。報告保留這次的前後數量，後來賣掉的貨不會改寫原差異。資料先存在目前裝置，請定期下載完整備份；儲存空間不足時先保持頁面開啟，保留草稿並重試。
