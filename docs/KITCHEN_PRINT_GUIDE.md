# 廚房列印：看狀態，按下一步

開發分支驗證中，尚未包含於既有 2.16.0 安裝檔。所有店家、全部功能免費。

1. **老闆先設定一次。** 在「預訂出餐 → 廚房列印」按「選印表機、試印」。回到廚房列印，選備餐單語言，核對實際紙張與文字，再保存。需要自動列印才勾「接單後自動印」。
2. **店員照常接單。** 正式接單後才保存備餐列印工作；顧客剛送出點餐不會直接出備餐單。手機與電腦看同一張單，由店面電腦送印。
3. **看到紙張，再確認。** 「已送印，請確認紙張」表示傳輸已完成。實際紙張正確才按「紙張正確」。需要再印一份，展開「列印細節 → 需要補印」，先核對可能已印過的紙張。

顯示「核對上次列印」時直接按它，系統沿用原編號，不另開一筆。列印待核對仍可繼續收銀。紙本結果不明時不會自動重送；補印會帶副本編號，避免廚房誤認新訂單。

取消已送印的餐點後，取消通知仍可在「需要核對的紙張」查看。還原或換電腦後須重新核對印表機；搬入的舊待印工作會保留供查詢，不自動送印。

店面電腦須保持開機。獨立瀏覽器可核對搬入紀錄，沒有原生送印服務時不能自動送印。實體印表機的字集、紙寬、切紙、缺紙，真實手機及長時間營業仍待驗收；受控 TCP 接收器不是實體紙張。Uber Eats／foodpanda 仍未串接。工程要求見 [列印規格](KITCHEN_PRINT_SPEC.md)。
