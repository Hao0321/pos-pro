# POS Pro 2.9.1 安裝與更新

本機建置檔名：`release/2.9.1/POS Pro Setup 2.9.1.exe`。原始碼與版本標籤、安裝檔、GitHub Release 附件需分別核對；本輪沒有上傳 Release 安裝附件。

本版修正手機共用服務啟動／停止衝突，以及直接結束程式時漏掉服務清理的路徑。關閉時先停止新的網路操作並收尾連線，之後才關閉 SQLite。未完成請求會斷線，已提交交易保留原單號供核對。詳細流程與限制見 [安全關閉](SAFE_SHUTDOWN.md)。

更新前先下載完整 JSON 備份並另存裝置外；關閉舊程式後更新，再核對帳號、庫存、訂單、採購與備份。手機須在電腦更新、共用服務啟動後重新連線。

安裝檔未做 Authenticode 簽章，仍採人工更新，沒有可信自動更新來源。建置紀錄包含來源版本、輸入與產物雜湊、SBOM 與第三方授權；必須另行核對安裝包內 payload，並用隔離設定檔驗證。隔離執行不等於已完成 Windows 真實安裝、移除或實體設備驗收。

本機曾觀察到原生程序退出延遲，仍未穩定達成每次 5 秒內退出；不以強制終止程序取代資料收尾。完整 ERP、真人易用性及實際營業長跑也仍未完成，見 [能力清單](../product-capabilities.json)。

2.9.1 未新增資料表或變更交易格式。已知前版 [2.9.0 安裝檔紀錄](INSTALLER_2_9_0.md)與完整備份保留供回退；降回更早版本時，仍須遵守原版對退貨與退款歷史的相容限制，不以舊備份抹除已發生交易。
