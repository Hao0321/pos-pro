# 直接交 Excel 搬家

## WM1 — 選檔、選資料、看結果

店主直接選 `.xlsx`，選要搬的工作表及標題列後，沿用商品、供應商、客戶的欄位核對與一次確認。同一份檔案的三類主檔可同批原子搬入，先保存供應商再接商品關聯，不要求使用者自行拆檔或分批排序。只有原編號與名稱欄能唯一證實資料類型、且工作表可見時才預選；不明或隱藏工作表請使用者選擇。標題列以上、空白列、隱藏列及合併儲存格的處理須看得見，不默默漏掉有值的資料。

這是完整 ERP 搬家的一段。舊式 `.xls`、任意廠牌完整轉接、期初庫存、帳款、歷史帳、試搬與撤回仍在完整目標內，不能以 XLSX 主檔測試取代。全部功能免費。

## WM2 — 原檔與解讀計畫一起保存

使用封閉的 `pos-workbook-migration/v1`：原系統與公司、檔名、原始 ZIP 的 Base64、明確的來源幣別，以及每張所選工作表的 ID、標題列、既有欄位用途、原系統編號欄、共同單位、逐格修正。完整內容決定批次編號。前台不能傳入任意已解碼表格作為正式事實。

所有核對及寫入權威從原始檔與計畫重新推導主檔。回執、下載紀錄、完整備份與冷重開均保留原檔、選擇及修正；相同來源編號沿用既有對照，不重複建檔，不蓋掉本店未核對的修改。

## WM3 — 資料型別不能猜

共用與內嵌字串、富文字文字段、中文、空白及 Unicode 保留；稀疏儲存格不向左位移。依 [Microsoft Xstring 規格](https://learn.microsoft.com/en-us/openspecs/office_standards/ms-oe376/bd0aa042-434a-4ca7-b25f-4e1fd25a954d) 逐文字段解碼跳脫字元，不重複解碼跳脫後的底線。數字只做等值十進位整理，科學記號精確展開，不先經浮點數或四捨五入；例如數字 `120.0000` 是 `120`，文字型編號不去零。純補零格式可還原顯示編號，原始數值及格式仍留在檔案中。

公式永不執行，快取結果不直接當事實。被套用的公式、錯誤或不能解讀的格式需填入已核對的值；已知庫存、儲值、點數與帳款仍不能在主檔入口修成零。日期依檔案的 1900／1904 日期系統處理，無效的 1900-02-29、時間小數或無法證實的日期格式要求核對。不能從格式中的 `$` 猜幣別；商品金額須有明確新台幣來源，其他幣別先保留待換算。

單元格文字、網址、公式與 XML 都只當來源資料。沒有網路取用、巨集、外部實體或作業系統執行權。

## WM4 — 有界解碼與相容保護

原檔暫限 120,000 bytes，JSON 草稿仍受既有 250,000 bytes 限制；解析 ZIP 另限制項目數、個別及合計解壓大小。驗證路徑、唯一性、壓縮方式、邊界、長度與 CRC，拒絕加密、ZIP64、多卷、重疊或不一致資料。不把 ZIP 解壓到檔案系統。

XML 須是格式正確的受支援 Open XML，限定節點、深度、儲存格與文字量；拒絕 DTD／自訂實體，依正確 namespace 及 package 關聯定位工作表、字串與樣式。資料列與標題列超過讀取上限時不能只取前幾筆就顯示成功。

新來源增加持久 `agent-workbook-migration-v1` 功能保護與復原版本 12；未使用的 CSV／TSV、Agent JSON 仍維持原格式。真實前版 native writer 與 browser reader 必須在修改前拒絕不了解的新來源。

## WM5 — 同一條實際操作鏈驗收

先保存來源，才准提交。驗收須走實際 XLSX 檔案、工作表／標題列、欄位與公式修正、店主核對、原子提交、失敗回覆、冷重開、原結果查回、匯出、完整備份，以及 native、獨立瀏覽器和配對 HTTPS。

使用獨立試算表工具生成的檔案校準共用／內嵌字串、日期與補零；另外保留破損 ZIP／XML、壓縮炸彈、錯誤關聯、重複座標、公式快取、跨來源編號、隱藏資料、非零期初、假店主、quota 與晚期 SQL 失敗等負控制。介面維持四語、兩種風格及手機觸控；真實使用者與實體裝置另行驗收。

依據：[Microsoft 儲存格型別](https://learn.microsoft.com/en-us/office/open-xml/spreadsheet/how-to-retrieve-the-values-of-cells-in-a-spreadsheet)、[公式與快取值](https://learn.microsoft.com/en-us/office/open-xml/spreadsheet/working-with-formulas)、[fflate 有界輸出 API](https://github.com/101arrowz/fflate/blob/master/src/index.ts)、[saxes XML 行為](https://github.com/lddubeau/saxes)。這些文件提供格式依據，不是本產品通過驗收的證據。
