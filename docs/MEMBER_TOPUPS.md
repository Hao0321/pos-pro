# 會員儲值

到「會員」選一位會員，再按「儲值」。輸入本次實際收到的金額，選現金或電子付款；畫面會自動算出儲值後可用餘額。店主可展開「加贈金額（選填）」；贈額增加會員餘額，不會算成實收現金。

核對畫面上的姓名、手機與金額，確定已收到款項，再按「確認儲值」。本功能只記錄收到的款項，不會向支付平台扣款。

輸入還沒完成時按「稍後再填」。回來按「接著完成儲值」，可接續原始輸入；重新載入也會保留。草稿依店面、登入帳號與還原世代隔離。同一帳號另一視窗須等待原視窗離開會員頁後接手。

若另一位會員仍有未完成的儲值，先接回原筆核對；新選的會員不會取代原筆。會員姓名、手機或班次更新時，須明確核對最新會員或改用目前班次，才可儲值。

保存途中斷訊時，按「核對原儲值」。找不到時才使用「用原編號再核對」。原紀錄與金額確認後才清除草稿，請勿重新收款或另開一筆。已入帳的原筆即使原班次結束，也會沿用原班次確認，不會轉記到新班次。

金額可輸入一般數字、全形數字或正確千分位，例如 `1,000.50`。最多接受兩位小數；不會把 `1e3`、不完整金額或多餘小數自動猜成另一個金額。無法保留草稿時會停止送出，保留畫面內容。

## 工程驗證

```text
node node_modules/vite/bin/vite.js build
node node_modules/vitest/vitest.mjs run tests/security/member-topup-draft.test.js
node scripts/run-native-security.cjs --member-topup-ui
node scripts/run-native-security.cjs --member-topup-browser-ui
```

檢查使用隔離資料。360px Chromium 與自動流程不代表實體手機、長者或兒童真人已完成驗收。會員福利設定、會員資料修改與完整企業 CRM 仍有各自的範圍。
