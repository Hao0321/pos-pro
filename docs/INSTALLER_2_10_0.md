# POS Pro 2.10.0 安裝與更新

產品定位為 **POS Pro｜ERP・點餐・CRM**，所有店家、全部功能免費。新版以鈷藍、黑、米白重做登入、首頁、選單、共用元件、顧客點餐、演練及 Windows／手機圖示；ERP、顧客點餐與會員 CRM 共用同一品牌，完整產品能力保持 [清單](../product-capabilities.json) 的原範圍。

本機建置檔名：`release/2.10.0/POS Pro Setup 2.10.0.exe`。原始碼與版本標籤、安裝檔、GitHub Release 附件需分別核對；本輪沒有上傳 Release 安裝附件。

## 本版操作

- 首頁分成「顧客與點餐（CRM）」和「營運管理（ERP）」，附白話介紹；共用同店面資料，保留直接收銀、快速建單與跨工作區搜尋。
- 貼上單一 Agent 完整回覆就能核對；一般文字保留「幫我整理」。
- 明細顯示單價、單位、小計、合計；商品可搜尋，缺資料按「下一步」會帶到該欄位。
- 這個裝置會保留依店面、帳號與角色隔離的未完成草稿，重開保留原編號、時間與價格版本。正式資料仍以店面資料庫為權威。
- 保存結果未確認時鎖定原單，使用「確認這張單的結果」重試；新連結等原單核對後才讀取。
- 銷售／預訂交給 Agent 的預設資料包不附成本與供應商；採購不附店內售價；不附配方及公司對照表。公開目錄及個別客戶報價仍是後續功能。
- 外送文字與外部單據的來源說明不代替地址；必須明確補上地址備註。

## 更新與驗證範圍

更新前先下載完整 JSON 備份並另存裝置外；關閉舊程式後更新，再核對帳號、庫存、訂單、採購、會員及備份。手機在電腦更新並啟動共用店面後重新連線。

安裝產品名仍為 POS Pro，appId 及既有資料目錄保留；沒有重建店面、搬移正式資料庫或變更交易格式。未完成草稿是新的本機畫面暫存，前版不會顯示，正式單據與待確認交易紀錄不受此暫存取代。

安裝檔未做 Authenticode 簽章，仍採人工更新，沒有可信自動更新來源。建置紀錄含來源版本、輸入與產物雜湊、SBOM 及第三方授權；交付時另外核對實際封裝內的程式，使用隔離設定檔驗證。隔離執行不等於 Windows 真實安裝、移除或實體設備驗收。

本機原生程序退出時間仍未穩定達成每次 5 秒內，見 [安全關閉與已知限制](SAFE_SHUTDOWN.md)。真實長者／兒童試用、手機設備、印表機、店內網路及長時間營業仍須實測，不宣稱全面零 Bug。
