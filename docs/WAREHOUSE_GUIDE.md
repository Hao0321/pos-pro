# 貨放在哪裡，搬多少

所有店家、全部功能免費。目前供開發驗證，成本開帳仍未公開啟用；既有 2.16.0 安裝檔尚未包含本流程。

只有一個店面，照常進貨與收銀即可。有備貨區才需要另外設定地點。

1. **選商品與地點。** 在「搬貨、存放地點」選商品，選從哪裡搬、搬到哪裡。畫面會顯示各處剩多少，以及另外預留多少。
2. **填搬多少。** 可直接填基礎數量。店主若已設定「1 箱 = 12 個」，選箱後填 1，系統會自動算成 12 個。
3. **搬好後確認。** 按「看搬貨結果」，核對商品、數量、來源與目的地，實際搬好才按「已搬好，確認記錄」。

放在備貨區的貨，搬回店面後才會列入收銀及點餐可售量。預訂已預留的貨不會被搬走；搬貨保留原成本，不會另算一次進貨或付款。

看到「核對上次搬貨」時，沿用這個按鈕確認原紀錄。輸入會保留在原裝置；不要為了重試再開一筆。獨立瀏覽器沿用一次一個 POS 頁面的保護，關閉原頁後在另一頁重新載入；手機共用店面則操作電腦上的同一份資料。

店主可展開「新增地點、設定包裝」，設定地點名稱及每個商品的包裝含量。員工可以搬貨，不可修改這些設定。

完整備份會保留地點、包裝比例、來源區間與搬貨原編號。使用此功能後，需要支援 `warehouse-v1` 的程式繼續操作；舊版會停止寫入。批次效期、過期隔離、FEFO、在途及多地點盤點仍待接通，不能把本階段視為完整倉儲管理。工程要求見 [完整規格](WAREHOUSE_LOT_UNIT_SPEC.md)。
