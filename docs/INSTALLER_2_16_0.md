# POS Pro 2.16.0 本機安裝檔

本版新增「供應商與預付款」：實際付出的訂金先保留為供應商餘額，再抵付同一供應商的多張請款，避免付第二次。部分解除、收到原款退回及更正都保留原紀錄。現金連結班次，銀行只記錄已核對的付款事實，不發起轉帳。

預設一位管理員即可使用；需要分工時，才啟用另一管理員帳號核准。原提案保留當時要求，切回簡單模式不會放行舊待核准單據。Agent 可準備付款草稿，仍需使用者核對；提案及核准不會自動付款。兩種模式、所有店家及全部功能均免費。操作見 [供應商指南](SUPPLIER_GUIDE.md)。

保留明亮簡約、海報風格及繁中、英文、日文、簡中；切換不改寫商家的名稱、備註、價格、幣別與帳本。修正有效舊報價的建單時間檢查，以及重開同一份 Agent 採購時沿用完整原請求的相容性問題。

本機交付路徑為 `release/2.16.0/POS Pro Setup 2.16.0.exe`；實際產物及驗證結果以對應成功建置收據為準。本頁不是公開下載連結，建置不會自動上傳 GitHub Release。正式建置要求安全解包、實際程式登入與交易、供應商核准／付款／跨單抵付、完整復原及重啟檢查。舊版資料庫需以隔離副本與固定雜湊驗證，不能用新建資料夾代替升級測試。

更新前另存完整備份，關閉舊程式再更新。保留已驗證的 2.15.1 安裝檔及升級前備份；新供應商帳本一旦啟用，舊程式會被阻擋繼續寫入，不能直接降版後操作同一份資料。需要回退時，應使用原先另存的升級前副本；保留新帳本供核對，避免漏掉升級後的交易。

安裝檔未簽章，採人工更新。完整 ERP／CRM、完整升級矩陣、真人易用性、母語校對、實體設備及實際安裝移除仍需各自驗收，不宣稱零 Bug 或第三方資安／會計認證。
