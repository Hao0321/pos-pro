# POS Pro — はじめに

すべてのお店に、すべての機能を無料で提供します。サブスクリプションや機能の追加料金はありません。

初回は端末の言語から対応する表示言語を選びます。ログイン画面でいつでも **日本語** に変更できます。**明るくシンプル** または **ポスタースタイル** のプレビューを押すと外観を切り替えられます。スマホではログイン後も画面上部の言語アイコンから変更できます。手動で選んだ設定は端末ごとに保存し、端末の言語より優先します。

1. Windows 版をインストールし、自分の管理者アカウントを作成します。
2. **商品・在庫** で商品名・価格・単位・原価・実際の数量を登録します。
3. **営業を始める・締める** で準備金を確認し、営業を開始します。
4. **商品を売る・お金を受け取る** で商品と金額を確認し、実際の入金を記録します。
5. 営業前にバックアップを作り、使用するプリンターも試してください。

**お客様・注文（CRM）** は会員・ポイント・チャージ・注文、**お店の運営（ERP）** は商品・仕入れ・在庫・支払い・帳簿を管理します。同じお店のデータを共有するため、登録し直す必要はありません。

**かんたん伝票** には Agent の返信全文を貼り付けられます。商品・数量・価格を確認してから確定してください。言語を変えても下書きと元の番号を保持します。保存結果が未確認の場合は再度集金せず、元の取引を確認・再試行してください。

スマホも使うには、Windows 版の **端末を接続** から共有を開始します。同じ店舗内 Wi-Fi またはテザリングに接続し、店舗の証明書を確認して信頼した後、使い切りのペアリング用リンクでログインしてください。パソコンと POS は起動したままにします。スマホの表示言語は別に選べます。保存には店舗パソコンへの接続が必要です。

表示言語を変えても通貨や税制は変わりません。本版は既存の TWD／NT$ の会計ルールを維持します。商品名や備考は入力した原文を保持します。完全な ERP・企業向け CRM は開発中で、翻訳には母語話者による校正が必要です。

現在の Windows 版は未署名で、手動更新です。更新前にバックアップしてください。[インストール情報](INSTALLER_2_13_1.md)・[言語と外観](LANGUAGE_AND_STYLE.md)も参照できます。

## 見積・価格表

ホームで「見積」を検索します。「見積・価格表」で購入側の店舗情報カードを貼り付け、商品・数量・単価を選びます。TWD 建ての全費用を含む合計と有効期限を確認して保存し、コピーまたはダウンロードしてご自身で送信してください。以前の版は残り、取引先ごとの参考単価を別々に記憶できます。

仕入れる場合は「自分の店舗情報をコピー」で仕入先に店舗情報を渡します。届いた見積を「かんたん伝票」に貼り付け、商品の対応・仕入先・日付・金額を確認して仕入伝票を作成します。入荷と支払いは別の操作です。

公開価格表には選択商品の参考価格だけを含みます。店舗情報カードや宛先 ID は会社の身元を認証したり、ファイルを暗号化したりするものではありません。合意した連絡手段で相手を確認してください。他社 ERP／Agent は公開 JSON schema から実装できますが、独立した相互運用と母語話者による校正は今後の検証事項です。

## 販売・売掛金

合意済みの見積で「取引先が同意済み：受注へ」を選ぶか、ホームで「未入金」を検索して手動で受注を作成します。取引先・数量・単価を確認して確定してください。この手順は受注の記録のみで、在庫の減算・引当や入金処理は行いません。

商品を合意どおり渡したら「次へ：商品を引き渡す」で今回の数量と支払期限を確認します。実際に代金を受け取ったら「この代金の入金を記録」で金額と方法を保存します。一部入金も可能です。現金は開いているシフトに記録し、銀行入金は確認済みの事実だけを記録します。銀行への自動請求は行いません。

返品・値引きは元の引渡し、返金は元の入金に紐づきます。訂正は元の履歴を保持します。商品原価を変更しても元の引渡し原価で集計します。保存結果が不明な場合は「元の操作結果を確認」を使用してください。

現段階は TWD 建ての全費用込みの商品販売と内部請求の流れです。前受金・複数請求への一括消込・完全な在庫引当・税務請求書・決算処理は開発中です。[操作ガイド](SALES_GUIDE.md)も参照してください。
