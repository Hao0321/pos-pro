# 首頁先做一件事

簡易首頁先顯示目前適合的主要操作：尚未開班時「帶我開始營業」，已有購物車時「繼續這筆收款」，其他營業時間則是「賣東西、收款」。這些按鈕只帶到原有畫面，不會自行開班、建單或收錢。

「幫我建單」直接進入原有建單流程。其他功能集中在「其他工作」，可以用白話搜尋，也能選「顧客與點餐 CRM」或「營運管理 ERP」。查詢會搜尋所有有權限的工作；清空查詢後回到原本選擇的工作區。第一次使用的說明與搬家入口保留在這裡，按 Escape 可收起並回到入口。

簡易側邊選單保留常用入口與目前頁面。「全部功能」可展開其他項目，換頁後恢復精簡；切換完整操作時仍顯示完整選單。權限、未確認交易、備份與連線提示、原有金額核對均沿用既有系統。

自動畫面、按鍵與交易資料檢查不能代替老人、小孩的真人易用性驗收。其他頁面的閱讀負擔、實體手機與安裝檔驗收仍未完成。本輪僅為原始碼更新。

開發驗證：建置後以 scripts/run-native-security.cjs 的 --home-focus-ui 與 --home-focus-browser-ui 執行隔離的實際畫面流程；對應單元測試為 tests/security/workspace-home-ui.test.jsx 與 workspace-tasks.test.js。比較原版文字與入口數量時，須另外保留同一店面資料、視窗尺寸、語言和風格的前版實際畫面，不能以通過數量代替真人理解。
