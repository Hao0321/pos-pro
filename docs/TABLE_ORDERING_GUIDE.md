# 掃桌碼，到餐點交給客人

開發分支的新流程；尚未包含於既有 2.16.0 安裝檔。所有店家、全部功能免費。

1. **老闆：填桌數。** 先確認「預訂出餐」的菜單、配方與產能，再展開「桌碼點餐」，填桌數、按「產生桌碼」，下載後放在對應桌上。
2. **客人：選餐、確認。** 掃桌碼會自動帶入桌號。選餐後核對數量及金額；送出後可看取餐號與進度。
3. **店員：接單備餐。** 在「新點餐」按「接單備餐」，同一張單就會進入工作單。接著按「開始製作」「餐點好了」，核對實際款項、登記收款，再「交給客人」。

客人送出並不代表已收款。店員接單時才預留成品或原料，庫存與產能不足會停止接單。手機須使用「共用店面」的配對入口，與電腦操作同一份資料。

畫面顯示「核對原訂單」時，直接按它確認上一筆。系統會沿用原單號；先保留畫面與紀錄，避免再開一張。原料、售價或桌碼改變，也不會把已收到的原請求當成新單。

目前提供電子備餐工作單，[自動廚房列印](KITCHEN_PRINT_GUIDE.md) 正在隔離環境驗證。Uber Eats／foodpanda 自動收單，以及真實手機、印表機和長時間營業驗收仍待完成。獨立瀏覽器可處理完整備份搬入的原單；新的公開點餐服務由店面電腦提供，電腦須保持開機且顧客裝置能連到點餐網址。此階段未啟用公網通道。
