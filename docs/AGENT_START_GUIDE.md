# Agent 幫你建單、準備搬家

所有功能免費。以下入口在開發分支，尚未包含於既有 2.16.0 安裝檔。

## 建單

1. 首頁按「Agent 幫我建單」，選這次要開的單。
2. 複製建單資料給你的 Agent，再把回覆帶回系統。
3. 看商品、數量與價格，確認後保存。

整箱進貨可在採購頁按「Agent 幫我建單」，選檔、拖入或貼上回覆。原本的日期、備註與未提供的私價會保留；一箱有幾件、原單多少錢，由你核對後自動換算。建採購單不會自動收貨或付款。

收貨時再看一次「實際入庫商品」與單位。供應商目錄換連結後，系統會要求重新核對，避免把貨加到另一個商品。新商品要確認售價，系統不猜售價。

## 從其他系統搬入主檔

1. 首頁按「Agent 幫我搬家」，選舊系統匯出的 XLSX、UTF-8 CSV／TSV，或 Agent 草稿，也能貼上表格。
2. 核對原編號、欄位與缺少的資料；Excel 可把商品、供應商與客戶工作表一起核對。再看新增、更新與保留筆數；有資料差異時，選擇要保留的內容。
3. 按「確認搬入這批資料」。若結果中斷，重開後按「核對上次結果」。

目前支援商品、供應商與客戶主檔，也可接續搬入原庫存。原編號、原文字與來源欄位會保留，相同來源重跑不重複建立。本店已修改的內容先請你核對。點數、儲值、未收付款及歷史帳仍須另行對帳，不能直接當成一般交易搬入。選檔與核對不會把原檔送到外部 AI 服務。

## 把原庫存帶過來

1. 交進有「數量、庫存總成本」的原報表，按「看搬家核對結果」。有原庫存資料時，會直接接續這一步。
2. 選原資料是哪一天的，只補缺少或有疑義的格子；幣別不明時才確認幣別。原報表另有庫存總額，也可以一起核對。
3. 看商品、保存後數量和庫存價值，再按「確認搬入期初庫存」。

系統先試算整批結果，確認後才一起保存。售價不會當成成本，也不會多開一筆進貨或銷售。原庫存報表若沒有售價，會接上先前確認的商品原編號，不猜成零元商品。本店已有庫存、需要批號／倉庫資料或其他帳款時，會先要求核對。

斷線或沒收到結果，重開按「核對上次結果」，不用重新搬一次。可以下載完整原檔、修正與搬入紀錄。這一步完成表示這批庫存已保存；其他帳款與整套系統切換仍須完成對帳。見 [原庫存規格](OPENING_MIGRATION_SPEC.md)。

若尚未整理檔案，展開「Agent 與備份」，按「複製給 Agent」。目前需由使用者把原系統匯出檔提供給 Agent；這個入口沒有自動登入其他廠牌帳號。原始檔、欄位對照與修正會一起保存，在同一裝置重開也能繼續；手機與電腦共用正式搬入的店面資料，未完成草稿目前各裝置分開保留。CSV／TSV 上限 80,000 bytes，XLSX 上限 120,000 bytes；舊式 XLS 需先另存 XLSX。見 [表格規格](TABULAR_MIGRATION_SPEC.md) 與 [Excel 規格](WORKBOOK_MIGRATION_SPEC.md)。

Excel 公式不會執行，也不直接採用舊快取值；只請你補已核對的資料。數字補零、日期與稀疏位置保留，隱藏資料列一起核對。來源金額須明確使用新台幣；其他幣別先保留待換算。工作表勾選及標題列以上的範圍都會顯示，整批確認後才保存。

如果你是用本系統的完整備份換電腦，按「搬入 POS Pro 完整備份」，沿用 [完整備份換機流程](COMPLETE_BACKUP_GUIDE.md)。

給 Agent／開發者的規格入口是 [`/llms.txt`](../public/llms.txt) 與 [公開 manifest](../public/agent/manifest.json)。公開規格不含本店的客戶、庫存或私價。
