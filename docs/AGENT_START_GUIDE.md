# Agent 幫你建單、準備搬家

所有功能免費。以下入口在開發分支，尚未包含於既有 2.16.0 安裝檔。

## 建單

1. 首頁按「Agent 幫我建單」，選這次要開的單。
2. 複製建單資料給你的 Agent，再把回覆帶回系統。
3. 看商品、數量與價格，確認後保存。

整箱進貨可在採購頁按「Agent 幫我建單」，選檔、拖入或貼上回覆。原本的日期、備註與未提供的私價會保留；一箱有幾件、原單多少錢，由你核對後自動換算。建採購單不會自動收貨或付款。

收貨時再看一次「實際入庫商品」與單位。供應商目錄換連結後，系統會要求重新核對，避免把貨加到另一個商品。新商品要確認售價，系統不猜售價。

## 從其他系統搬入主檔

1. 首頁按「Agent 幫我搬家」，選舊系統匯出的 UTF-8 CSV／TSV，或 Agent 草稿，也能貼上表格。
2. 表格先核對原編號、欄位與缺少的資料；再看新增、更新與保留筆數；有同名或資料差異時，選擇要保留的內容。
3. 按「確認搬入這批資料」。若結果中斷，重開後按「核對上次結果」。

目前支援商品、供應商與客戶主檔。原編號、原文字與來源欄位會保留，相同來源重跑不重複建立。本店已修改的內容先請你核對。庫存、點數、儲值、未收付款及歷史帳仍須另行對帳，不能直接當成一般交易搬入。檔案不會自動上傳外部服務。

若尚未整理檔案，展開「Agent 與備份」，按「複製給 Agent」。目前需由使用者把原系統匯出檔提供給 Agent；這個入口沒有自動登入其他廠牌帳號。原始文字可在次要區域查看。表格原文、欄位對照與修正會一起保存，重開也能繼續。表格上限 80 KB；原生 Excel 檔需先另存成 UTF-8 CSV。見 [表格搬家規格](TABULAR_MIGRATION_SPEC.md)。

如果你是用本系統的完整備份換電腦，按「搬入 POS Pro 完整備份」，沿用 [完整備份換機流程](COMPLETE_BACKUP_GUIDE.md)。

給 Agent／開發者的規格入口是 [`/llms.txt`](../public/llms.txt) 與 [公開 manifest](../public/agent/manifest.json)。公開規格不含本店的客戶、庫存或私價。
