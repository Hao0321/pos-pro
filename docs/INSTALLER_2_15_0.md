# POS Pro 2.15.0 本機安裝檔

本版加入共用客戶、預收款、一次抵付多張交付請款、部分解除抵付、原收款退款與更正。收到的錢先保留為客戶預收，交貨與收款分開記帳；會員儲值仍保留原本的獨立來源。詳見 [客戶款項操作指南](CUSTOMER_GUIDE.md) 和 [功能規格](CUSTOMER_LEDGER_SPEC.md)。

明亮簡約、海報風格及繁中、英文、日文、簡中都涵蓋新流程。未送出內容會依裝置保存；送出前將草稿綁定原操作編號，回覆不明時沿用原編號核對。私人 HTTPS 手機使用電腦同一份帳本。報表也修正漏翻文字，商品分析改用實際歷史價款及已保存成本。

本機交付路徑為 `release/2.15.0-verified/POS Pro Setup 2.15.0.exe`；實際產物與驗證結果以對應建置收據為準。本頁不是公開下載連結，建置不會自動上傳 GitHub Release。

更新前建立並另存完整備份，關閉舊程式再更新。保留已驗證的 2.14.1 安裝檔與升級前資料副本。首次保存客戶帳後會建立資料庫相容性寫入保護：舊版不能忽略已抵付款項繼續收款。需要回退時，必須使用升級前的資料副本，不能直接把升級後的帳本交給舊版寫入。

所有店家、全部功能免費。安裝檔未簽章，採人工更新；完整 ERP／CRM 仍持續開發。自動驗證不等於 NSIS 實際安裝移除、實體手機與周邊、真人易用性、母語校對、可信更新或所有舊版升級皆已驗收，也不宣稱零 Bug。
