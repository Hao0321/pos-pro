# POS Pro 2.7.0 安裝與更新

本版所有店家、全部 POS 功能免費。Windows 安裝包檔名為 `POS Pro Setup 2.7.0.exe`，本機產物放在 `release/2.7.0/`。GitHub 原始碼 tag 與安裝包是不同交付項目；未上傳至 GitHub Release 的本機檔案不會自動出現在 Releases 下載頁。

## 更新前

1. 從既有 POS 下載完整 JSON 備份，確認檔案實際保存，另存到裝置外。
2. 完成或核對待確認的收款／退款，正常關閉舊 POS，再執行安裝包。
3. 啟動後核對店名、帳號、最近訂單、庫存與開班狀態，再使用新模組。更新不重建既有帳號或加入示範交易。

程式目前採人工下載與安裝，沒有可信任的自動更新通道。安裝包未簽章，Windows 可能顯示未知發行者；請核對取得來源與交付收據中的 SHA-256。本版未替使用者設定防火牆、憑證信任、自動啟動或公開網路服務。

## 新增與修正

- 正式預訂、現場／外送登記、原料與包材預留、產能、每日取餐號、出餐、全額收款與取消退款。
- 手機／電腦使用同一間店的 SQLite；斷線保留原操作編號，返回頁面後恢復同步。
- 進貨、盤點、儲值、交班與備份的完整回執及原子保存；保留零值設定、歷史時間與穩定資料版本。
- 混合付款按現金／非現金入帳；已製作退單保留損耗費用；已扣庫損耗不可直接刪除財務證據。

驗收使用隔離資料庫與設定檔，不修改正式店面資料。測試與實機邊界見 [營業可靠性](OPERATING_READINESS.md)，手機配對見 [共用店面](SHARED_STORE.md)。
