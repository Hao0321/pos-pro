# 試算表檢視與資料交換

帳務日記帳與損益 CSV 是供人查看的匯出：文字欄位完整引用並跳脫逗號、引號與換行，防止原文跑到其他欄。可能被當成公式的文字（包括日文環境的全形前綴）加上文字防護；真正的有限數字保留數字型態，負數不改成文字。

防護只影響下載檔，不改寫商家名稱、單據、帳本或 Agent 資料。防護字元會是 CSV 文字的一部分，因此此檔不作為逐字往返的資料交換格式；需要保留原文時使用既有 JSON 備份／Agent 協議。

設計參考 [OWASP CSV Injection](https://community.owasp.org/attacks/CSV_Injection)。CSV 在不同試算表或另存再開啟後的處理並不一致，本機序列化測試不代表實體 Excel／LibreOffice 已驗收。商品匯入用的資料交換 CSV 與試算表檢視格式保持分開。
