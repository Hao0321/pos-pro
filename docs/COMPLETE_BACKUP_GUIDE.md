# 換機，三步就好

開發分支預覽；尚未放進 2.16.0 安裝檔。所有店家、全部功能免費。

1. 舊裝置：在「設定 → 備份還原」按「下載完整備份」。
2. 新裝置：登入店主帳號，開啟同一頁，按「匯入備份」。
3. 看變動、勾選確認，再按「確認還原」。

電腦版與瀏覽器版可互相搬移。系統會自動辨識來源、核對格式，不用自己選。預覽會顯示來源裝置與一併帶回的保護副本。

目前帳號、密碼及連線憑證會保留。設定中的 0、false、空字串與文字也會保留原本的意思。

要找回還原前的資料？展開「還原前的副本」，選日期，按「找回這份資料」。不用搬舊裝置的待確認暫存。系統會先保存目前資料；已有新交易時會要求核對，避免覆蓋。

請另存備份檔到其他裝置。舊格式缺少完整保護紀錄時，畫面會提醒；看到「收款尚未確認」請先核對原單，勿再向客人收款。

配對手機的店主也可開啟「設定 → 備份還原」。資料仍由店面電腦保存；手機斷線時保留原編號，連線後先核對結果。店員沒有還原權限。要搬移含保護紀錄的資料，請使用完整備份；既有部分雲端快照不包含這些紀錄。

使用過新格式的帳本，舊程式會停止寫入；請保留原檔並使用相容版本。此項已用真正的 2.16.0 舊程式測試，仍須另做新安裝檔、實體設備與真人驗收。
