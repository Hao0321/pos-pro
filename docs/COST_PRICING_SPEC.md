# 自動換算成本與建議售價

本次使用者要求：成本、份量及售價自動換算；輸入簡單，不能把缺資料或估算說成正確實際數字。本里程碑補充原 31 項 ERP 要求與庫存成本 I1–I12，不取代任何未完成要求。

## C1 可核對的輸入

從商品編輯直接開啟，輸入包裝價格、每包內容量、每份用量，可增加食材與包材。整箱可填包數；可用比例由使用者確認，不能猜熟重、密度或損耗。每份等於這個商品出售的 1 個商品單位。固定 TWD，不猜匯率。

使用者追加回饋「字好多好怕看不懂」：改成一次一頁的「買多少 → 用多少 → 看結果」，前進時才顯示該步缺漏。成本可先算，售價等目標填妥才顯示。用「每賣 100 元，想留下幾元」取代前台毛利術語。公式、取位、資料範圍和裝置草稿說明收進「看明細」，保留費用現值、未列成本提示與核對防呆。

## C2 精確換算

十進位字串轉 BigInt 分數。kg/g/mg、L/mL、明確台斤 600g／市斤 500g 可同維度換算；重量、容量、件數不可互換。包／箱的內容量必須提供。中間值及逐行成本保留分數，全部加總後才向上取到分，顯示取位規則。0 元必須明確輸入，空白不是 0。

## C3 售價

毛利目標以售價為分母，與加價率區分。使用者提供抽成、每單固定費用及每單份數；預設「現場收款，費用 0」須清楚可見。每份其他費用可輸入，不自動推定租金、薪資、稅、配送費等。目標加抽成必須小於 100%。以已列成本及費用計算；抽成保守向上取到分，建議售價向上到使用者選定級距。搜尋滿足目標的最小售價，不能只套未驗證浮點公式。

## C4 核對後帶入

可列出每筆來源與公式，區分已列成本、其他未列成本。勾選核對後才可帶入商品草稿，仍需按商品儲存。計算本身不改庫存、不建財務分錄、不修改歷史成本。輸入改動即使結果與數值相同也要重新核對；已帶入後再修改試算時，商品儲存也必須擋住，直到重新帶入或明確手動改價。同店另一裝置修改原售價、參考成本或單位時，以原快照比對拒絕覆蓋，保留試算重新核對。草稿不可冒充共用已保存配方；提供帶輸入與完整分數的計算紀錄下載。

## C5 驗收

涵蓋混合單位、箱包倍數、可用比例、分數尾差、大數範圍、缺值／異維度／模糊斤／非法數字、毛利與加價率差別、極端費率、固定費分攤、最小級距、改輸入失效、確認後只帶入草稿、四語、360px 及兩種風格。輸入的真實性仍需店家以原單核對，不能宣稱現實資料永遠 100% 正確。
