# 接單、交貨、收款

首頁搜尋「收欠款」，或選「銷售與應收」。所有店家、全部功能免費。目前由管理員操作；配對手機與電腦共用原店面的訂單、可用庫存與款項。

## 已經有報價

1. 在「報價與價目表」打開客戶已同意的報價，按「客戶已同意，轉銷售單」。
2. 畫面會帶入客戶、商品、數量與原報價單價。核對後勾選客戶已同意，再按「確認接單」。
3. 接單成功後，畫面會告訴你下一步。重複開啟同一報價會回到原銷售單；之後修訂報價不會改寫已接的單。

沒有報價也能按「新增銷售單」，依序填「給誰 → 賣什麼 → 確認接單」。客戶代碼會先自動產生，可自行修改；往來過的客戶可直接選。商品名稱、客戶名稱、議定價格與備註會保持原文。

**接單不會扣庫存、收款或保留商品。** 這一步只是記下雙方同意要賣的內容。

## 實際把貨交給客戶

按「下一步：交給客戶」，填本次實際數量和約定收款到期日，確認這批貨已依約交給客戶、可以請款，再保存。可分批交付；系統每次都重新檢查原店面的可用庫存，庫存不足會整筆拒絕。

交付成功才扣本批庫存、記錄當時成本與客戶應收。這裡的請款是內部紀錄，不是稅務發票。

## 客戶付錢了

在那一批交付按「收這筆款」，填實際收到的金額和現金／銀行方式，再保存。可以只收一部分；畫面會保留尚未收到的餘額。現金需先開班，並會計入該班現金；銀行只登記實際收款，不會向銀行或客戶自動扣款。

收款只減少客戶欠款，**不會再算一次營收**。總帳、報表與今日營業額會依原交付和退貨折讓計算，歷史成本不會跟著後來的商品改價重算。

## 退貨、折讓或款項記錯

打開該批的「退貨、折讓與款項更正」：

- 退貨：填本次數量、原因，選商品還能不能再賣。能再賣才回庫，並沖回原交付成本；不能再賣就不回庫。
- 折讓：填每個品項要減少的金額和原因。不會把同一筆價款重複折抵。
- 退款：退貨或折讓造成多收款時，選原收款退款。金額不能超過原收款剩餘可退額，方式沿用原收款。
- 記錯收款／退款：用原紀錄的更正操作並填原因，保留原始紀錄。有效退款需先更正，才可更正它引用的收款。
- 不再交剩餘商品：到「完整紀錄與其他操作」結束剩餘訂購。已交貨、應收和退款仍會保留。

## 斷線、重開與備份

保存結果不明時，按「確認原操作結果」。系統沿用原編號核對；不要另開一張或重新向客戶收款。重新載入仍可復原待確認操作。

完整備份包含銷售文件、交付、收款、退貨折讓、退款、更正、操作人與正式回執。還原舊備份後，若原操作回執已不在該快照中，系統保留待核對狀態，不自動重做收款。舊雲端快照尚未包含完整資料時會停止同步；可用完整 JSON 備份或私人共用店面。

目前是 TWD、全部費用包含在單價內的商品銷售流程。預收款、一次核銷多張請款、完整庫存預留、稅務發票與關帳仍未完成，不能把本頁當作完整 ERP 已完成或所有國家稅制都適用的證明。
