# 快速建單草稿

快速建單保留尚未整理的文字、原始建單編號、數量，以及外部公司的品項對照。草稿只放在這台裝置；正式訂單、庫存和採購仍以店面的資料為準。

換帳號、角色、店面或還原備份後，使用不同的草稿範圍。同一台裝置的兩個視窗編輯同一份草稿時，後開的視窗等候；前一個離開該頁後，另一個接回最新輸入。

採購與預訂在實際送出前，先保留原操作的編號與內容證明。保存回覆中斷後，重新開啟這台裝置的原草稿，會先核對已保存的完整回執，再完成原表單；結果不明時保留原編號，不能自動另開一單。

重新貼上已建立的採購或報價，會先核對原單，再處理現在的價格或效期。已建立時直接顯示原金額，按「查看單據」就開啟原單；不會再收貨或付款。同編號卻有不同採購條件時，保留輸入並提示核對。[原單核對範圍](QUICK_ORIGINAL_IMPORT_SPEC.md)另有說明。

「帶入收銀台」只把商品放到收銀台，之後仍需確認收款。收銀台已有商品時，保留原購物車。

舊版草稿沒有還原版本識別，不會自動套入目前畫面。按「接回舊版草稿」才會把輸入保存到目前範圍，再先找已建立的原單；已接受的過期報價可以直接顯示原金額。尚未建立時才重新核對目前店內資料。可先下載原檔；讀不到或核對失敗的草稿不會自行覆蓋，兩份原內容仍保留。

已建立新版綁定單據的資料會保留最低相容版本保護；不支援相關格式的舊程式會停止開啟，請使用相容版本。本次查原單不新增資料格式，前一個支援 format9 的開發版仍可讀寫帳本，但不支援新的查詢流程。回退驗證使用升級前的完整備份另存副本，不能把新格式資料交給不相容的舊版改寫。

這份規格屬本機開發分支。產能與配方草稿另見 [設定接回規格](RESTAURANT_SETTINGS_DRAFT_SPEC.md)。顧客未送出購物車、菜單同欄位衝突的簡易選值、真人與實體裝置驗收、完整 ERP 及新安裝檔仍需接續完成。
