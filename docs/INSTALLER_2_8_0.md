# POS Pro 2.8.0 安裝與更新

所有店家、全部功能免費。本機 Windows 安裝包路徑為 `release/2.8.0/POS Pro Setup 2.8.0.exe`。原始碼與安裝包分開驗證，本機檔案不代表已上傳 GitHub Release。

這版加入 [ERP 採購到付款](ERP-FOUNDATION.md)：新採購可分批收貨、登錄供應商請款、分次付款與沖銷，並產生相互連結的分錄及現金班次流水。手機使用既有私人區網配對入口；獨立 PWA 不會自動合併其他裝置的資料。

另提供 [Agent 快速建單](AGENT_DOCUMENT_PROTOCOL.md) 與 [跨公司交換草稿](BUSINESS_EXCHANGE.md)，支援文字、商品按鈕、JSON 檔／拖放／草稿連結及共用的品項對照，並可切換全系統大字模式。

更新前先用原版本匯出完整 JSON 備份，再關閉程式。新版本保留帳號與舊單，只新增可空白的採購資料欄位；舊單不自動補造歷史分錄。新採購產生的完整資料須使用新版完整 JSON 備份，不能透過舊版雲端快照覆蓋。

保留 2.7.1 安裝檔與更新前備份供回復。舊版程式不理解新的採購歷史；需要回復時，使用另存的更新前資料與相符版本，避免讓舊版覆寫新版採購文件。

安裝包沒有 Authenticode 簽章，更新採人工審查與比對 SHA-256；未建置信任簽署的自動更新。沒有替店家啟動服務、自動啟動、公網隧道、安裝憑證或修改防火牆。

實際硬體、手機憑證信任及 Windows 安裝／移除流程需在目標設備驗收；隔離 SQLite、Electron 與手機尺寸 HTTPS 操作不等同所有實機驗證。
