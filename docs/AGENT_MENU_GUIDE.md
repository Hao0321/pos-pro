# 讓 Agent 幫你填餐點

1. 打開「快速建單」，選「預訂餐點」，按「複製建單資料給 Agent」。
2. 貼給你自己的 Agent，告訴它要哪些餐點、份量與加料。
3. 把完整回覆貼回「快速建單」，看清餐點與總額，補上取餐資料，再確認建立。

貼回前不會送單。建單只預留庫存，收款需另行確認。

可以分開點正常份、大份、加蛋與套餐。想修改時，展開餐點下面的「修改份量與加料」。不使用 Agent，也可以直接點餐點，或輸入「現場牛肉丼2，下午五點」這類完整品名與數量。

菜單或價格改了，按「重新核對餐點」，看新總額後再確認。如果顯示保存結果還在確認，按「確認這張單的結果」核對原單，避免另開一張。

資料包不包含餐點的原料、成本或庫存。草稿保留一天；已送出但回覆不明的原單，重開仍使用原編號確認。

沒有份量與加料的普通商品也使用相同三步驟。一天內的草稿會先按店內最新資料核價，確認時使用當下的核價時間；原草稿的編號和時間仍保留。看到價格更新時，請重新核對總額再確認。

這是開發分支功能；既有安裝檔尚未包含本次改版。真實外部 Agent、第一次使用者、實體手機與營業現場仍待驗收。技術格式見 [餐點草稿協議](../public/agent/restaurant-draft-v1.schema.json)。
