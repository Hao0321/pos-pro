# 選餐點、看預覽、保存

這是本機開發中的菜單設定，既有2.16.0安裝檔尚未包含。所有店家、全部功能免費。

1. 在「預訂出餐 → 菜單與加料 → 設定菜單」選現有商品，按「加入餐點」。正常份會帶入商品售價及現有配方。
2. 需要時加大小份、加料或複製成套餐。用「展開現有配方」直接調整每份用量，例如庫存用kg，仍可填200g；系統會精確換算。單位不相容或太細時會請你調整。
3. 按「下一步：核對菜單」。可以展開用量與參考成本，或用「試點看看」選加料、少飯及份數，直接核對合計。確認後按「保存並啟用菜單」。

「不使用的原料」會從原份量移除該原料；減少部分用量可填負數，例如 -50g。套餐直接選現有商品與包材，售價與製作份數由老闆確認。參考成本使用已填的商品成本，並不代替實際批次成本或真實重量。

另一台裝置改過菜單時，按「核對店內最新」。同一欄有兩個版本，就選「保留我填的」或「用店內最新」，再按「套用選擇，再核對」。用量與單位會一起選；套用只改草稿，仍須另外預覽、確認保存。更改不會改寫舊訂單。

若出現「核對上次菜單保存」，直接按它；電腦或配對手機會沿用原編號查回，確認前先保留紀錄。需要更多協助可進「資料復原」。配對手機使用店面電腦同一份資料，電腦須保持開機。

未完成輸入與尚未套用的選擇會保留在這個裝置，跨頁或重開可接回。若店內又改了菜單，舊選擇會請你重選，不會自動發布。出現無法保存的提示時先保留畫面；可用草稿提示的下載入口留底。見[草稿指南](DRAFT_RECOVERY_GUIDE.md)與[選擇規格](MENU_CONFLICT_CHOICES_SPEC.md)。實體設備與長者／兒童真人驗收仍分別進行。
