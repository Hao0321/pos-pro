# 店員接單

1. 到「預訂出餐」，按「新增正式訂單」。
2. 點餐點，選份量、加料和份數，再按「加入訂單」。
3. 按「下一步：確認餐點」，核對總額與取餐資料，再按「確認接單並預留」。

接著在出餐工作單開始備餐。收款仍需另行登記；接單本身不表示已收款。

正常份、大份、加蛋與套餐會各自保留。價格改變時，重新核對顯示的新總額；原料不足時，可回去移除或調整餐點。錯誤不會自動清空原選擇與聯絡資料。

若顯示「核對上次接單」，按這個按鈕確認原單，避免再開一張。重開程式後也沿用同一筆已送出的原編號。

沒有設定選項的商品可從「其他商品」建單；目前與菜單餐點分開建單。未送出的草稿尚未支援離開頁面或重開後繼續，請先完成接單。

這是開發分支功能；既有安裝檔尚未包含本次改版。真實手機、印表機、營業現場及第一次使用者仍待驗收。
