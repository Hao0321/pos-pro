# 收據沒印出來，怎麼辦？

1. **先看結帳。** 顯示「結帳完成」就已記錄收款，不要再收一次錢。
2. **再看紙張。** 按「列印收據」後，系統會顯示送印進度。顯示已送印或結果待核對時，先查看印表機與紙張；需要再印，按「需要補印 → 確認補印」。已拿到就按「已拿到收據」。
3. **繼續接客。** 列印不會阻擋下一筆收銀。要找回收據，在收銀台按「找收據」，輸入單號或商品，選「查看收據」。

手機與獨立瀏覽器可以查看原單，紙本請到店面電腦列印。補印只印原收據，不會再次收款或扣庫存。

此流程在開發分支，既有 2.16.0 安裝檔尚未包含。實體印表機與實機手機仍待驗收；工程要求見 [收據流程規格](RECEIPT_PRINT_SPEC.md)。
