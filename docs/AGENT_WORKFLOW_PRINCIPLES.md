# Agent 共用入口的產品原則

使用者要讓換系統與建單都不用再學一套繁瑣流程。這是產品設計目標，並非已完成所有廠牌整合或市場競爭調查的宣稱。所有功能免費。

共同操作是「交資料 → 看結果 → 一次確認」。同一個來源編號不用重建，來源缺欄不清除店主已填內容，只有不確定的地方才請人決定。選檔、拖入與貼上通往同一個核對權威；手機與電腦共用同一間店的帳本。

標準協議負責讓不同 Agent 看懂資料，系統負責身份、單位、金額、原子保存與原結果核對。Agent 只準備事實，不把模型猜測當實際庫存、私人價格、付款或授權。失敗時保留原文與進度，不要求使用者重填整份。

公開規格、原始來源與來源對照可隨完整備份帶走。互通的價值是讓人省事並保有選擇，不依賴封閉格式。CSV／TSV 與有界 XLSX 的欄位核對已接通，同一 Excel 可一次核對三類主檔。完整廠牌轉接、舊式 XLS、期初與帳款對帳、跨裝置草稿接續、外部 Agent 及真人首次使用持續保留在完整驗收範圍。
