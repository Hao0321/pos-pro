# 批次怎麼盤點

1. 首頁按「實際點一下庫存」。
2. 選商品；有多個存放地點時，再選地點。
3. 按批號填「我點到多少」。沒數的留空；真的沒有才填 0。
4. 按「看差異」，核對後「確認保存」。系統自動調整庫存與成本。

架上的貨包含還沒開始製作的預留。已投入製作的材料不算架上；暫停販售的貨要切到「暫停販售」另外數。數量少於預留量時，先核對原訂單。

同一批盤出額外數量，成本先標成待確認；系統不會猜進貨價，也不會把隔離貨恢復販售。原先的批次與成本來源都保留。

要交給 Agent：展開「讓 Agent 幫填本頁」，複製資料包，提供實際數量，貼回回覆，再核對差異。Agent 貼回只會填草稿。

離開或重開會接回草稿。看到「核對上次盤點」就核對原編號，不要再建一筆。

此流程在開發分支，先核對庫存成本並啟用批次後使用；既有安裝檔尚未包含。實際手機、真人易用性及長時間營業仍待驗收。工程規格見 [批次盤點規格](LOT_COUNT_SPEC.md)。
