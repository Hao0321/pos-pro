# POS Pro 2.15.1 本機安裝檔

本版修正報表的 ABC 商品優先順序：只有一種商品、或單一商品占大部分營收時，會保留在 A 類優先商品；跨過分界的完整商品留在該優先區間。零或負營收不會產生假的優先商品，沒有正營收時匯出佔比為 0，分級依正營收合計計算。

分級說明提供繁中、英文、日文、簡中，沿用明亮簡約與海報風格。2.15.0 的共用客戶、預收、跨單抵付、退款、更正及原編號復原均保留，見 [客戶款項指南](CUSTOMER_GUIDE.md)。本版沒有更換帳本格式。

本機交付路徑為 `release/2.15.1/POS Pro Setup 2.15.1.exe`；實際產物與驗證結果以對應建置收據為準。本頁不是公開下載連結，建置不會自動上傳 GitHub Release。

更新前另存完整備份，關閉舊程式再更新。保留已驗證的 2.15.0 供回退；未使用客戶帳功能的升級前副本與 2.14.1 也應另存。使用客戶帳後，不支援此功能的舊版會被阻擋寫入，不能直接交給舊程式繼續收款。

所有店家、全部功能免費。安裝檔未簽章，採人工更新；完整 ERP／CRM、真人易用性、母語校對與實體設備驗收仍有待完成，不宣稱零 Bug。
