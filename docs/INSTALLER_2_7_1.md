# POS Pro 2.7.1 安裝與更新

所有店家、全部功能免費。本機 Windows 安裝包為 `release/2.7.1/POS Pro Setup 2.7.1.exe`。GitHub 原始碼及 tag 與安裝包分開交付；本機檔案尚未上傳 GitHub Release。

本版修正小數原料損耗、重複點擊、失敗保留輸入與原編號復原；台灣凌晨跨日／跨月的損耗、帳務、費用及進貨日期一致，活動期間兼容舊本地時間並拒絕倒置時間。

更新前下載完整 JSON 備份並另存到裝置外，核對待確認交易，正常關閉舊版。安裝後確認店名、帳號、訂單、庫存及開班狀態，再開始營業。既有帳號與正式預訂紀錄應持續保留。

安裝包未簽章，目前採人工更新。請核對取得來源與交付收據中的 SHA-256。包內執行檔、隔離啟動／重開與前版資料升級另行驗證；這不等於已在使用者電腦執行 NSIS 安裝或驗收實際手機、憑證與印表機。

驗收範圍見 [營業可靠性](OPERATING_READINESS.md)，手機配對見 [共用店面](SHARED_STORE.md)。先用實際營業設備做完整演練，再帶到攤位。
