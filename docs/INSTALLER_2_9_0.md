# POS Pro 2.9.0 安裝與更新

本機建置檔名為 `release/2.9.0/POS Pro Setup 2.9.0.exe`。原始碼與版本 tag 可推送 GitHub；本輪沒有上傳 GitHub Release 安裝附件。不能只從檔名推定已下載到最新版本。

## 更新流程

1. 在舊版先建立並下載完整 JSON 備份，另存到裝置外。
2. 關閉舊程式，再執行經核對來源的安裝檔。手機共用店面應在電腦更新完成後重新連線。
3. 開啟後核對原帳號、商品庫存、訂單、採購與備份，再開始營業。

安裝包目前未做 Authenticode 簽章，採人工更新。沒有可信自動更新器，也沒有替使用者開啟自動啟動、公網隧道或防火牆。不要把隔離的程式執行測試當成 Windows 安裝、移除與實機營業已驗收。

## 新增內容

- 預設簡易首頁、白話搜尋、常用工作與待處理提醒；全部功能仍免費開放。
- 一鍵複製給 Agent 的建單說明與店內資料；單一 JSON 區塊可直接導入。舊連結不會重開已處理的草稿，手動修改會清掉舊預覽。
- 採購部分退貨、原請款折抵、供應商待退、分次退款與退款更正；沿用交易、班次與完整備份。

## 驗證與回退

建置程式保存來源 revision、完整輸入及輸出雜湊、內含檔案清單、SBOM 和第三方授權。交付核對須另外驗證安裝包內的實際 payload 與這份來源一致，再用隔離設定檔啟動該 payload；真實 NSIS 安裝與移除另行驗收。專案功能驗證見[營業可靠性](OPERATING_READINESS.md)。

2.9.0 的退貨及退款歷史不應由舊版直接修改。需要退回舊程式時，保留現行完整備份並使用更新前的舊版備份，不能用降版抹除已發生的退貨或款項。前版 2.8.0 安裝檔保留作已知版本；不在本輪嘗試清除先前被政策拒絕的檔案。
