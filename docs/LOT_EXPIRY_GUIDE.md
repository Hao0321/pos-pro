# 批次與效期：選商品、填日期、確認

開發分支提供，尚未包含於既有 2.16.0 安裝檔。所有店家、全部功能免費；成本開帳仍未公開啟用。

1. **選商品。** 首頁找「批次與效期」。店主首次核對店面時區，再選商品與原庫存／進貨紀錄，數量會自動帶入。
2. **填這批效期。** 批號可不填；只填這批實際知道的日期與數量。不知道的日期保留空白，系統不猜。
3. **確認保存。** 核對商品、數量和日期。之後預留、收銀及交貨會先使用較快到期的合格批次，成本跟著原來源走。

「有效期才可販售」由店主選擇。啟用後，未確認效期的貨會暫停販售；填妥可用日期後才回到可售庫存。已過期的批次一律停賣，原先預留的貨到期也不能直接開始製作或收款。

**暫停販售不等於報廢。** 貨和原成本仍保留。核對原包裝後可由店主更正日期，已隔離的過期品另按「恢復販售」並填原因；實際丟棄才按「報廢這批」。員工可記錄報廢，批次和效期規則由店主設定。

耗損頁與匯出沿用原批次成本。成本不知道會顯示待確認；後來修改商品參考單價，不會改算原本那批貨的實際損失。

退貨與未開始的預訂取消沿用原批次；已過期的貨回到暫停販售，不會因退款自動上架。「核對上次批次操作」會沿用原編號，回覆中斷時直接核對這筆。

手機使用「共用店面」與電腦操作同一份資料；獨立瀏覽器可保存同樣的完整備份。每批盤點、到貨批次引導、隔離品退供應商與在途調撥仍待接續完成。實體裝置、老人兒童真人理解及長時間營業尚待驗收；完整 ERP 目標仍在開發。
