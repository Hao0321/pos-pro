# POS Pro 2.14.1 本機安裝檔

本版把安裝檔交付檢查接入正式建置指令：自動校準負控制、檢查完整解包內容，並用解包出的執行檔完成主要流程與重啟核對，通過後才回報建置成功。建置工具改用鎖定 SHA-256 的官方 7-Zip 26.04。詳見 [建置與驗證流程](BUILDING_AND_VERIFICATION.md)。

本機交付路徑：release/2.14.1/POS Pro Setup 2.14.1.exe。本機建置不會自動上傳 GitHub Release；本頁不是公開下載連結。實際產物與測試以對應收據為準。

所有店家、全部功能免費，沿用明亮簡約／海報兩種風格、四種語系、私人 HTTPS 共用店面及 2.14.0 的備份復原保護。完整 ERP／CRM 持續開發。

本版另補齊會員統計、會員分群、四類促銷條件與同步時間翻譯，畫面日期跟隨所選語言。會員詳情使用兩欄統計，手機可完整查看並返回原會員；店面資料、售價與 TWD 幣別維持原設定。

安裝檔未簽章，採人工更新。更新前建立並另存完整備份，關閉舊程式再更新；保留已驗證的 2.14.0 與對應資料副本。自動交付檢查不等於 NSIS 實際安裝移除、實體設備、真人易用性、母語校對、可信更新或所有舊版升級都已驗收，也不宣稱零 Bug。
