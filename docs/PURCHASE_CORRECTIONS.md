# 供應商付款更正與採購取消

採購 → 選進貨單 →「更正這筆付款」或「取消這張採購」。原金額、付款方式、日期與來源已帶入，只需選常用原因或自行填寫，再核對確認。沒有收貨與帳務的採購才可取消；已收貨應使用既有退貨流程。

原因會依店面、帳號與帳本世代保存。可先保留、換頁或重開後接續。切換語言不改寫已輸入的原因；新選的常用原因才採用當前語言。這個簡單理由欄位直接提供常用選項，無需再把取消／更正意圖交給 Agent 猜測。

付款更正會撤回整筆付款紀錄，原金額與方式取自原付款，不能在更正表單修改。若是金額記錯，撤回後再從原採購記錄正確付款。現金更正將原支出加回核對過的目前班次，保留原付款及已關班歷史；換班後需明確更新核對，不能自動改用另一班。銀行款項必須先自行核對；本功能沿用既有帳務更正，不執行銀行轉帳。

若保存回覆中斷，先「核對這次保存結果」。系統查實際原單、操作回執與完整現金流水，確認後才清除對應待確認命令。查不到時保留原因與原編號，不能直接另建一筆；其他待確認操作不會被清除。後續付款、收貨與其他有效資料仍以目前帳本為準。

取消與付款更正沿用原採購、供應商、現金及會計交易；原紀錄均保留。其他人已更正、取消或收貨時，會要求更新原單並保留原因，不能繼續套用過時資料。

本次交付限原始碼草稿。真人、實體手機、完整安全與發佈驗收另列未完成項目；不代表整個 ERP 已完成或零錯誤，也不會自動更新安裝檔。
