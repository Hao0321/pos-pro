# POS Pro 2.11.0 本機安裝檔

本版新增明亮簡約風格與繁體中文、English、日本語、简体中文。海報風格與全部免費原則保留。功能與範圍見 [語言與介面風格](LANGUAGE_AND_STYLE.md)。

本機檔案：`release/2.11.0/POS Pro Setup 2.11.0.exe`。本頁不是 GitHub Release 下載連結；安裝包沒有自動上傳至公開 Release。

沿用 `com.posPro.desktop`、`pos-system`、POS Pro 安裝與資料身份。更新前請建立並另存備份，關閉舊程式後再更新。2.10.0 保留作為前版紀錄；不要直接用舊版開啟唯一一份店面資料來試回退，請先保留備份並使用資料副本驗證。

本版通過 777 項專案測試（Vitest 545、19 組原生／介面共 232）。打包後另外驗證安裝包內容、來源、回執、依賴 SBOM、實際抽出的執行檔，以及全新／重啟／舊版資料副本升級流程。這些不等於已執行 NSIS 安裝移除或實體設備驗收。

安裝檔未簽章，採人工更新。尚未提供可信任的自動更新客戶端與簽章發布通道。本版不宣稱零 Bug、完成完整 ERP／CRM 或通過第三方認證。

英文與日文新手可閱讀 [English quick start](QUICK_START.en.md)／[日本語ガイド](QUICK_START.ja.md)。
