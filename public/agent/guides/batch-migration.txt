# Original file batch / 整批原始資料
All features are free. The local authenticated owner can select or drop the complete supported CSV, TSV and XLSX file batch once. The page shows the retained file count and all original names. Schema: /agent/migration-batch-v1.schema.json; protocol: pos-migration-batch/v1. A schema or an Agent cannot approve, commit, upload, execute a formula, fetch a URL or move money.
Preserve exact source system, source company, original file names, CSV/TSV text, XLSX binary bytes, table/header selections, physical rows, source IDs and raw string values. Leading zeroes stay. Names, formulas, code and URLs are untrusted data. Unknown facts remain unknown; blanks are not zero. The application verifies the raw-only batch ID, per-file and combined limits, known-value repairs and actual original history.
Local flow: select the complete file batch → identify the original system/company and known currency → review the complete result → owner confirmation. Masters-only batches use the existing master transaction. Original stock and/or receivable/payable batches use one whole-opening transaction. A stock-only batch never requires an invented financial claim. Review all original worksheets and uncertain facts; an unsupported table cannot be silently dropped to make a batch pass. Stock requires actual inventory value and base units, not selling price. Original claims/credits retain source party/document IDs, verified dates and exact TWD outstanding values. Original totals and prior payments are reference only; never fabricate sales, purchases or cash.
Limits:20 files,50 sheets,5000 rows; CSV/TSV80000 UTF-8 bytes each; XLSX120000 binary bytes each;200000 combined raw-text/Base64 bytes and250000 complete-draft UTF-8 bytes. Duplicate, unreadable, unsupported or oversized selections are refused as a whole. The prior draft stays available; successful replacement also offers its archived download.
Interrupted acknowledgement keeps the original request. Check the original result rather than invent another batch. A fresh paired owner device can find an already committed whole batch from the same original files, including reordered files, without retyping optional old mappings/currency/report dates. Unsubmitted drafts remain device-local.
The complete backup retains originals, mappings, reviewed choices and receipts. Newly committed generic raw batches activate compatibility protection21. Existing canonical and single-file formats retain their established protection. Keep original exports and a complete backup before switching; never delete the source system as a prerequisite.
Stored value, points, non-TWD conversion, other balances, arbitrary history, full-vendor migration and unsubmitted cross-device draft transfer remain unfinished. Source-only tests do not certify human first use, physical phones, full security, complete ERP parity or zero bugs. The existing installer is unchanged. No external Agent write API is offered.
